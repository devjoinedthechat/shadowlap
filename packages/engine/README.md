# @shadowlap/engine

The Shadowlap engine: RFC 8785 canonical JSON, fingerprints and normalizers, the replay session (call-key matching), structural diff, the SQLite store, the pack format and redaction. Used by `@shadowlap/sidecar` and the `shadowlap` CLI; you rarely need it directly.

Docs: https://github.com/devjoinedthechat/shadowlap
