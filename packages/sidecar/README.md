# @shadowlap/sidecar

The Shadowlap sidecar: a loopback record/replay proxy for model APIs (Anthropic, OpenAI-compatible, Gemini) and the call resolution API the SDKs talk to. Start one with `Sidecar.start({ store })`, or use the `shadowlap` CLI, which does it for you.

Docs: https://github.com/devjoinedthechat/shadowlap
